# Mixmonster – Download

Hier gibt es die neueste Version von **Mixmonster** für Android.
von [FGSeRaser](https://github.com/FGSeRaser)

➡️ **[Neueste Version herunterladen](../../releases/latest)**

1. Die Datei `Mixmonster-….apk` auf dem Handy herunterladen.
2. Öffnen und „Installieren“ tippen. Beim ersten Mal fragt Android, ob Apps aus dieser Quelle installiert werden dürfen – einmal erlauben.
3. Neue Versionen meldet die App von selbst. Dein Spielstand bleibt beim Aktualisieren erhalten.
